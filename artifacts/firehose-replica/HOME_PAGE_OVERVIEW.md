# Rozeta Labs — Homepage Overview

## What This Page Is

This is the main marketing homepage for **Rozeta Labs**, an AI-powered revenue recovery and operations transformation service for small and medium-sized businesses (SMBs). It lives at the root path `/` of the `firehose-replica` artifact and is the primary entry point for all organic, paid, and referral traffic.

---

## Intention

The page has one job: convert a skeptical SMB owner into booking a free audit.

Every section is sequenced to move the visitor through a specific psychological journey:
1. Identify the problem they already feel but haven't named
2. Educate them on what's actually possible (and why most of the market is doing it wrong)
3. Show them the concrete systems Rozeta builds
4. Prove the value with a direct cost comparison
5. Remove the risk with pricing transparency and a no-pay guarantee
6. Give them a clear, low-friction next step

There is no passive content. Every section either moves the visitor forward or answers an objection.

---

## What It Conveys

- **Rozeta is an embedded AI team, not a software tool or agency.** They go cross-org, audit every department, and build custom automations and applications around your specific business — not a generic template.
- **There are three levels of AI maturity.** Most businesses are stuck at Level 1 (basic rules-based automation). Rozeta moves them to Level 2 (intelligent, context-aware automation) and Level 3 (autonomous agents + custom applications that operate without human input).
- **The first automation goes live in 14 days, guaranteed.** If they don't deliver, you don't pay.
- **It's a flat membership, not agency hourly.** The Costco analogy: pay a flat fee, get everything built for you at cost — no markups, no retainer games.
- **You can't do this yourself for anything close to this price.** The value comparison section makes this explicit with real numbers.

## How The Page Is Set Up

### Architecture
- **File:** `artifacts/firehose-replica/src/pages/Home.tsx`
- **Framework:** React + Vite, TypeScript
- **Routing:** Single-page; this is the root route `/`
- **Component structure:** All sections are defined as named React functions within the same file. They are composed in a single `Home` export at the bottom.

### Data
All content is defined as constants at the top of the file:
- `ROTATING_WORDS` — array of 8 industry types for the hero typewriter
- `USE_CASES` — 5 revenue recovery systems (id, label, description)
- `PROCESS_STEPS` — 5 engagement steps (id, label, description)
- `DEPARTMENTS` — 7 department cards with icon and audit blurb
- `AI_AGENTS` — 4 agent showcase cards (icon, industry, title, description)
- `CUSTOM_APPS` — 3 custom application showcase cards
- `vcLeftItems` — cost breakdown for the "Without Rozeta" panel
- `vcAutomations` — automation list for the "With Rozeta" panel
- `vcAgents` — agent list for the "With Rozeta" panel
- `vcExtras` — extras list for the "With Rozeta" panel

### Interactive Elements
- **Hero typewriter** — cycles through 8 industry words at 3.5-second intervals with character-by-character type/delete animation
- **StreamDemo accordion** — clickable buttons expand to show system descriptions; one active at a time
- **Value Comparison mobile tab toggle** — switches between "Without Rozeta" and "With Rozeta" panels on small screens
- **Floating mobile CTA** — appears after 500px scroll on small screens only
- **Card hover animations** — all feature cards lift up 2px with deeper neo shadow on hover

### Design System
- **Color palette:** Yellow `hsl(47,100%,50%)` (primary accent), Cream `hsl(46,100%,96%)` (light background), Black `#000` (borders, text, dark backgrounds), White `#fff` (card backgrounds), Blue `hsl(210,100%,56%)` (secondary sections), Red `hsl(0,85%,70%)` (accent)
- **Typography:** Space Grotesk, bold/extrabold weight, all-caps tracking throughout
- **Borders:** All elements use `border-4 border-black` (4px solid black borders) — zero border-radius anywhere
- **Shadows:** Neo-brutalist offset drop shadows — `shadow-neo-sm` (3px 3px 0 0 #000), `shadow-neo-md` (6px 6px 0 0 #000), `shadow-neo-lg` (8px 8px 0 0 #000)
- **Section separators:** Every section uses `border-b-4 border-black` to create hard visual breaks
